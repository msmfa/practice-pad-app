
# Practice Pad

### A macOS scratchpad for mastering the most commonly asked JavaScript interview questions


Practice Pad gives you 24 classic interview problems `debounce`, `throttle`, `Promise.all`, `deep
clone`, `currying`, and more

<img width="1572" height="1061" alt="Screenshot 2026-08-18 at 01 23 36" src="https://github.com/user-attachments/assets/693a0e9b-5815-44a1-9780-23651beffdbc" />

## Features

- #### AI assistant powered by Claude that can assist you when you're stuck on a question
- #### A built-in test runner
- #### A tracking tab that shows you the progress you're making
- #### Different difficulty levels 
- #### A pomodoro timer

## Download

Grab the latest signed, notarized build from the [Releases page](../../releases/latest).
Open the `.dmg`, drag Practice Pad into Applications, and launch it like any other Mac app.

Currently built for Apple Silicon (arm64) Macs.

## Using your own Claude API key

Click the gear icon in the app to add your own key from the [Claude Platform](https://platform.claude.com/settings/keys).
Encrypted on your device via the macOS keychain.
