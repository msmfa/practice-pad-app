# Practice Pad

A focused macOS scratchpad for practising JavaScript and TypeScript interview questions.

Practice Pad gives you 24 classic interview problems (debounce, throttle, `Promise.all`, deep
clone, curry, and more), each with three difficulty levels that build on one another, a built-in
test runner with hidden checks, and an optional AI reviewer powered by Claude that critiques your
solution when you ask it to.

## Download

Grab the latest signed, notarized build from the [Releases page](../../releases/latest).
Open the `.dmg`, drag Practice Pad into Applications, and launch it like any other Mac app — no
warnings, no right-click workarounds.

Currently built for Apple Silicon (arm64) Macs.

## Using your own Claude API key

The AI reviewer is optional and billed to you directly, not to this project. Click the gear icon
in the app to add your own key from the [Claude Platform](https://platform.claude.com/settings/keys).
It's encrypted on your device via the macOS keychain and never leaves it except in requests to
Anthropic.
